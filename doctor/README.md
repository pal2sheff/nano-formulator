# Подбор состава — врачебная версия

`index.html` — одна страница, работает офлайн. Без химии и технологии: направленность, синергия, взаимодействия, противопоказания по состояниям пациента, схема приёма.

Ядро, правила и база — из `../compat-calc` (технологическая версия, git-тег `tech-v1`). Своё — в `src/`:
- `doc-data.js` — направленность (17 направлений), время приёма, 17 состояний пациента и противопоказания, примеры;
- `doc-engine.js` — анализ (`analyzeDoc`), партнёры для карточки, текст заключения;
- `doc-ui.js`, `doc.css`, `template.html` — интерфейс.

    node build.js                 # собрать index.html
    node --test test/doc.test.js  # тесты
    node test/browser.js          # проверка в Chromium
