# Подбор индивидуальных рецептур

Два офлайн-инструмента на общей базе из 294 веществ (255 активных):

| Версия | Папка | На сайте |
|---|---|---|
| Для врача — синергия, направленность, противопоказания, формы доставки, метаболическая нагрузка | `doctor/` | `/vrach/` |
| Для технолога — pH, растворимость, химическая и физическая совместимость в лекарственной форме | `compat-calc/` | `/tehnolog/` |

Каждая версия — один HTML-файл (база, код и шрифты встроены), работает без интернета.

## Сборка
    node build-site.js          # обе версии + главная → docs/ (GitHub Pages)
    cd compat-calc && npm test  # тесты движка технолога
    cd doctor && node --test test/doc.test.js

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `docs`.

## Структура
- `compat-calc/data/molecules.json` — база веществ; `compat-calc/tools/` — добавление веществ (RDKit) и расчёт pH 1%.
- `compat-calc/src/` — ядро расчётов, правила совместимости, интерфейс технолога, фирменная тема.
- `doctor/src/` — направленность, противопоказания, формы доставки, мишени и метаболизм, интерфейс врача.
- `site/landing.html` — главная страница.

Все расчёты оценочные; решение о назначении принимает врач, о приготовлении — провизор.
