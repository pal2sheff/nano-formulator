# База веществ `molecules.json`

260 записей: вещества из списков Nano Identica («Молекулы 11.04.2026.xlsx», «Общий список активных веществ, ноябрь 2025»), вспомогательные вещества и основы. Структуры проверены RDKit по брутто-формуле; дескрипторы (cLogP Crippen, TPSA, HBD/HBA и др.) рассчитаны RDKit. Экспериментальные значения (pKa, logP, растворимость, т. пл.) — справочные (PubChem, DrugBank, Merck Index, Handbook of Pharmaceutical Excipients), округлены. Для экстрактов свойства даны по маркерному соединению или качественно.

## Поля

| Поле | Смысл |
|---|---|
| `id`, `ru`, `en`, `cat`, `kind` | идентификатор, названия, категория, тип: small, mineral, extract, enzyme, protein, peptide, polymer, probiotic, formulation, excipient |
| `fx` | брутто-формула активной частицы (из структуры) |
| `fs`, `mw` | формула и молярная масса формы поставки (соль, гидрат) |
| `mw_smi`, `ex` | молярная и моноизотопная масса структуры |
| `sf` | солевой фактор: доля активной части в форме поставки |
| `elem` | массовые доли элементов (Mg, Ca, Zn, Fe, Cu, Cr, Se, K, I) |
| `lp`, `clogp` | logP экспериментальный и рассчитанный (Crippen). Для расчётов: `lp ?? clogp` |
| `tpsa`, `hbd`, `hba`, `rotb`, `arom`, `hac`, `fsp3`, `mr`, `chir`, `ez` | дескрипторы RDKit, число хиральных центров и стереодвойных связей |
| `sw` | растворимость формы поставки в воде, мг/мл, 25 °C |
| `s0` | собственная растворимость нейтральной формы, мг/мл (для pH-зависимой растворимости) |
| `oil`, `eth` | растворимость в масле / этаноле: 0 — нет, 1 — слабо, 2 — хорошо |
| `mp` | температура плавления, °C |
| `ab` / `sp` | кислотно-основная модель. `sp` = список частиц `[pKa[], zf, z0, n]`: zf — заряд полностью протонированной частицы, z0 — заряд частицы в форме поставки, n — частиц на формульную единицу. Противоионы считаются сильными (−n·z0) |
| `p1` | рассчитанный pH 1% (10 мг/мл, с учётом растворимости) раствора в воде |
| `ph` | окно стабильности по pH в растворе `[min, max]` |
| `st` | устойчивость 0–3: `ox` окисление, `hy` гидролиз, `he` нагрев, `li` свет, `mo` влага |
| `tags` | теги свойств и фармакологии для правил (список — `tags_count.md`) |
| `alerts` | структурные признаки из SMARTS: catechol, pyrogallol, thiol, disulfide, thioester, amine1, amine2, aldehyde, ester, lactone, phosphate, quinone, polyene, michael, itc, diketone, flavonol, stilbene, dhp, nglyco, glycoside, quat, indole |
| `pI`, `seq`, `pep` | изоэлектрическая точка, последовательность и ионогенные остатки пептидов |
| `dose` | ориентировочный диапазон дозы, мг (для проверки правдоподобия ввода; у пептидов не указан) |
| `deg`, `salt`, `iso`, `poly`, `clin`, `marker`, `note`, `role` | текстовые заметки: деградация, соли и эфиры, изомеры, полиморфизм, клинические замечания, маркер экстракта, роль вспомогательного вещества |
| `taste` | вкус `t`, запах `s`, цвет `c` из файла аптеки |
| `pharm` | ID в базе аптеки `pid`, рекомендуемая форма `bf`, эффект `eff` |
| `svg` | структурная формула (SVG, линии `currentColor` под тему) |

## `src/core.js`

Готовые функции: загрузка базы из `<script id="db" type="application/json">`, производные теги, `alphas`, `meanCharge`, `solvePH` (баланс зарядов с фоновым CO₂), `neutralFrac`, `logD`, `solAt` (растворимость при pH), `cosolvFactor` (log-линейная модель сорастворителей), `oilSol` (оценка GSE), `pottsGuy` (поток через кожу), `toMg` (мг, мкг, г, МЕ, %), словарь форм `FORMS` и параметров `FORM_DEFAULTS`, насыпная плотность для капсул, заряд и pI пептидов, форматирование чисел.

Ограничения модели pH: не учитываются коэффициенты активности и комплексообразование металлов; для гидроалкогольных смесей значение ориентировочное.
