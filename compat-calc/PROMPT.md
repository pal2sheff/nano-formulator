# Задача для Claude Code: калькулятор совместимости и синергии для компаундинговой аптеки

## Контекст
Я врач, назначаю индивидуальные рецептуры в компаундинговой аптеке Nano Identica (Алматы). Нужен инструмент поддержки решений для врачей: проверить, можно ли объединить выбранные вещества в одной лекарственной форме, какие есть химические, физические и фармакологические противоречия и где комбинация даёт синергию. Окончательное решение остаётся за провизором; инструмент не выдаёт дозировок.

## Что уже есть (в этой папке)
- `data/molecules.json` — база из 260 веществ с физико-химическими свойствами, окнами стабильности, тегами и структурами. Описание полей — `data/README_DATA.md`, список тегов — `data/tags_count.md`, обзорная таблица — `data/molecules_overview.csv`.
- `src/core.js` — готовое расчётное ядро: pH смеси по балансу зарядов, ионизация и logD, растворимость при pH и в сорастворителях, оценка растворимости в масле, поток через кожу (Potts–Guy), пересчёт единиц, параметры лекарственных форм. Используй его, не переписывай без необходимости.

## Что сделать
Одностраничное приложение `index.html` (HTML + CSS + JS в одном файле, база встроена в `<script id="db" type="application/json">`), работает офлайн в браузере, интерфейс на русском.

### 1. Рецептура
- Выбор формы из `FORMS` (капсулы, порошок для напитка, капли водные, водно-спиртовые, масляные, спрей сублингвальный, троше, назальный спрей, крем, трансдермальная основа, гель, мазь, свечи ректальные и вагинальные) и её параметров из `FORM_DEFAULTS`: объём на приём, основа, наполнитель и оболочка капсулы, процент этанола и т. п.
- Добавление веществ поиском по русскому и английскому названию, количество на приём (мг, мкг, г, МЕ, %).
- Готовые примеры рецептур для быстрой проверки.

### 2. Анализ (пересчитывается при каждом изменении)
- Для жидких и водных форм: расчётный pH смеси (`solvePH`), растворимость каждого вещества при этом pH с учётом сорастворителей и признак «раствор / взвесь»; для масляных форм — оценка растворимости в масле.
- Проверка, попадает ли pH рецептуры в окно стабильности каждого вещества; при выходе за окно — какие компоненты сдвигают pH (пересчёт без каждого компонента). Пересечение окон стабильности: если оно пустое, указать конфликтующие пары.
- Совместимость каждого вещества с формой: фаза (вода, масло, сухая, расплав), нагрев при изготовлении троше и свечей, влага, свет, вкус для сублингвальных форм и троше, загрузка формы.
- Парная совместимость веществ. Правила составь сам на основе тегов, полей `st`, `ph`, `p1`, `alerts`, `elem` и фармацевтической литературы (Handbook of Pharmaceutical Excipients, Trissel's Stability of Compounded Formulations, USP <795>). Категории: химические (окисление, гидролиз, хелатирование, осаждение, ковалентные реакции), физические (растворимость, фазовые и вязкостные изменения основы), стабильность в форме, фармакологические (суммирование и антагонизм эффектов, противоречия по времени приёма, конкуренция за всасывание, ферменты метаболизма). Тяжесть учитывает фазу: в водной форме реакция идёт быстрее, чем в сухой капсуле.
- Синергия: известные полезные сочетания (биодоступность, кофакторы, взаимная стабилизация) — отдельным позитивным блоком.
- Для каждой находки: тяжесть (Несовместимо / Серьёзно / Умеренно / Учесть / Синергия), тип, вовлечённые вещества, механизм простым языком и что сделать (разделить, заменить соль или основу, буфер, антиоксидант, тара).
- Итоговый вердикт рецептуры и сводка: pH, осмоляльность для назальных форм, число и размер капсул, загрузка троше и свечей.
- Матрица совместимости «каждый с каждым» в выбранной форме (цветные ячейки, подсказка по наведению).
- Предложение разделить состав на совместимые группы (раскраска графа конфликтов) и подобрать каждой группе подходящую форму из того же пути введения.
- Кнопка «Копировать заключение» — текст рецептуры и найденных проблем.

### 3. Карточка вещества
Структура (`svg`), формула и масса формы поставки, солевой фактор, logP и cLogP, TPSA, pKa, pH 1% раствора, графики ионизации, logD и растворимости от pH 0–14, окно стабильности, профиль устойчивости, структурные признаки, заметки о солях, изомерах, полиморфизме и деградации, вкус и цвет, ID аптеки. ### 4. Раздел «Методика»
Какие модели использованы, их допущения и ограничения, источники.

## Ограничения
- Без инъекционных форм и без рекомендаций по дозам.
- Все расчёты помечать как оценочные.

## Дизайн
Аккуратный рабочий инструмент: светлая и тёмная тема, IBM Plex Sans и IBM Plex Mono (кириллица), цветовая кодировка тяжести, на телефоне колонки складываются в одну. Сначала сводка, потом детали.

## Проверка
Напиши небольшой набор тестов (Node), который прогоняет примеры рецептур через движок и сверяет ожидаемые находки. Например: НАДН с витамином C в водных каплях, медь с NAC и витамином C в каплях, лактоза с аминокислотой в капсуле, тадалафил с L-аргинином в троше, синефрин с мелатонином, куркумин с пиперином. После этого открой страницу и проверь, что она работает без ошибок в консоли.
