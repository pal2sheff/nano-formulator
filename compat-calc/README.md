# Калькулятор совместимости рецептур

Готовое приложение — `index.html` (один файл, работает офлайн, база и шрифты встроены). Откройте его в браузере.

## Структура
- `src/core.js` — расчётное ядро (без изменений): pH, ионизация, logD, растворимость, сорастворители, масло, Potts–Guy, единицы, формы.
- `src/rules.js` — правила: парные (химические, физические, фармакологические, синергия), групповые (суммирование эффектов), одиночные предостережения.
- `src/engine.js` — анализ рецептуры: pH и окна стабильности, растворимость, совместимость с формой, загрузка, осмоляльность, матрица, разделение на группы (DSatur), текст заключения.
- `src/ui.js`, `src/style.css`, `src/template.html` — интерфейс.
- `assets/fonts` — IBM Plex Sans / Mono (кириллица + латиница, OFL).
- `build.js` — сборка `index.html`.

## Команды
    node build.js                 # собрать index.html
    node --test test/engine.test.js   # тесты движка
    node test/browser.js          # проверка страницы в Chromium (Playwright): ошибки консоли, примеры, карточки

Правило добавляется в `PAIR_RULES` (`src/rules.js`) объектом `{ id, cat, type, a, b, sev: {W, D, M, L}, mech, act }`; после правки — `node build.js`.
