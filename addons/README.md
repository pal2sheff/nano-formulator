# Дополнения сайта

Каждое дополнение — отдельная папка `addons/<имя>/`. Основные версии (`compat-calc/`, `doctor/`) и главная страница не меняются.

## Как устроено
- `addons/<имя>/build.js` — собирает дополнение и кладёт готовые файлы в `addons/<имя>/dist/` (как минимум `dist/index.html`).
- `addons/<имя>/addon.json` — описание для главной страницы:
  ```json
  { "title": "Калькулятор митопаспорта", "tag": "Для врача", "path": "mitopassport",
    "desc": ["Что делает — пункт 1", "Пункт 2"], "landing": true }
  ```
  `path` — адрес на сайте (`…/nano-formulator/<path>/`), `landing: false` — не показывать карточку на главной.
- `node build-site.js` в корне сам находит дополнения, собирает их и копирует `dist/` в `docs/<path>/`. Папки, начинающиеся с `_`, пропускаются (например, `_template`).

## Что можно брать из основной части (только чтение, не изменять)
- База веществ: `compat-calc/data/molecules.json` (описание полей — `compat-calc/data/README_DATA.md`).
- Справочник конструктора аптеки: `compat-calc/data/site_catalog.json` (формы, рубрики, дозы с зонами, таблица несовместимостей).
- Расчётное ядро и правила: `compat-calc/src/core.js`, `rules.js`, `engine.js`, `site-core.js`; врачебные данные — `doctor/src/doc-*.js` (направленность, противопоказания, мишени и метаболизм).
- Фирменный стиль: `compat-calc/src/style.css` + `compat-calc/src/ni-theme.css`, шрифты — `compat-calc/assets/fonts/` (пример встраивания — `compat-calc/build.js`, `doctor/build.js`).

Нужно что-то поменять в общих файлах — это отдельная задача и отдельный pull request, не в рамках дополнения.

## Шаблон
`addons/_template/` — минимальное дополнение в фирменном стиле: скопируйте папку под новым именем без `_`.
